demo/

│   │   ├── java/com/krzysztof/demo/
│   │   │   └── DemoApplication.java                  <- punkt startowy aplikacji

│   │       ├── application.properties                <- konfiguracja (baza danych, port itd.)
│   │       ├── static/                                <- pliki statyczne (na razie puste, nieużywane u nas)
│   │       └── templates/                             <- szablony HTML (też nieużywane w REST API)
│   └── test/
│       └── java/com/krzysztof/demo/
│           └── DemoApplicationTests.java              <- testy (na razie pomijamy)
